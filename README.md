# 🌍 Geographie-Quiz

Interaktives Geographie-Quiz auf einer Weltkarte: Lerne Länder, Hauptstädte,
Flaggen, Flüsse und Gebirge. Die Karte basiert auf [Leaflet](https://leafletjs.com/).

## Lokal starten
`index.html` im Browser öffnen – kein Build, keine Installation nötig
(Leaflet wird per CDN geladen, also Internetverbindung erforderlich).

## Projektstruktur
```
index.html       → HTML-Markup
css/styles.css   → Styles
js/app.js        → Quiz- & Karten-Logik (Leaflet)
assets/          → Bilder & Medien
```
